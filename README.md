# CHROMA RIFT — Minestom 26.3

Это **серверная мини-игра для Minestom**, а не Canvas/браузерный рендер. Minestom запускает настоящий Minecraft-сервер; мир строится сервером из блоков, а участники едут по неоновой кольцевой трассе на персональных спортивных картах с открытым кокпитом.

## Требования

- JDK 25
- Minecraft Java 26.3 client
- Доступ к Maven Central и Sonatype snapshots при первой сборке

Проект использует snapshot `net.minestom:minestom:26_3-SNAPSHOT` из Sonatype, поскольку поддержка Minecraft 26.3 в Minestom пока публикуется как snapshot.

## Запуск сервера

```bash
./gradlew run
```

Подключись к `localhost:25565`. По умолчанию используется offline-auth для локальной разработки. Для публичного сервера включи Mojang/Microsoft auth:

```bash
MINESTOM_ONLINE_MODE=true ./gradlew run
```

Хост и порт настраиваются через `MINESTOM_HOST` и `MINESTOM_PORT`.

## Заезд

1. `/race join` — телепортироваться на старт и сесть в свой спортивный карт.
2. `/race start` — запустить трёхсекундный отсчёт.
3. Для одиночного теста используй `/race solo`: команда поставит тебя на старт и добавит трёх AI-пилотов. Затем введи `/race start`. `/race bots` добавляет AI после `/race join`.
4. Аркадное управление: **W** — газ, **A/D** — быстрый поворот, **S** — тормоз. Не нужно удерживать Sprint; поворот на скорости сам запускает дрифт и заряжает импульс.
5. Правый клик с ячейкой **PULSE CELL** даёт короткий нитро-рывок. Заезд начинается с тремя ячейками; дрифт возвращает потраченный заряд.
6. Обойди овал **три круга**, проходя четыре портала по порядку. `/race leave` — выйти; `/race status` — узнать состояние.

Движение и руление картом рассчитываются на сервере по вводу игрока. Клиентские пакеты перемещения машины отменяются, а игрок закреплён на невидимом zero-scale `ITEM_DISPLAY` внутри кокпита; видимая машина — отдельная синхронизированная 3D-модель, не вагонетка. Рекорды по UUID сохраняются в `data/chroma-rift-records.properties`.

## Кастомные машины и ресурс-пак

Gradle собирает `resource-pack/` в ZIP и вкладывает архив `chroma-rift-pack.zip` в серверный JAR. При входе клиент получает запрос на установку пакета. Внутри — четыре ливреи (cyan, magenta, lime, violet), низкий аэродинамический кузов, четыре широких колеса, передняя оптика, заднее GT-крыло и открытый кокпит с ковшом, приборной панелью и рулём. Машины — самостоятельные серверные `ITEM_DISPLAY`-модели; игрок сидит в кокпите, а не в вагонетке. След дрифта, частицы импульса и финишные эффекты работают на стороне Minestom.

По умолчанию встроенный HTTP-хост слушает `0.0.0.0:25566`, а для локального сервера URL ресурспака — `http://localhost:25566/chroma-rift-pack.zip`. Открой порт 25566/TCP для клиентов. Для публичного сервера укажи публичное имя/IP сервера с этим портом:

```bash
MINESTOM_RESOURCE_PACK_URL=http://play.example.com:25566/chroma-rift-pack.zip ./gradlew run
```

Для HTTPS используй домен, CDN или reverse proxy с TLS, направив его на встроенный HTTP-хост.

Путь и адрес HTTP-хоста настраиваются через `MINESTOM_PACK_HOST` и `MINESTOM_PACK_PORT`. Если ZIP размещён на внешнем веб-сервере или CDN, установи `MINESTOM_RESOURCE_PACK_URL` в его URL; встроенный хост всё равно можно отключить, задав `MINESTOM_PACK_PORT=0` (или используй другой порт/адрес).

## Реализация

- Java 25 + Minestom `26_3-SNAPSHOT`.
- Генератор Minestom строит обычный Minecraft-мир, неоновую трассу, ворота-чекпоинты и кристалл.
- `/race` (алиас `/rift`): до восьми участников (игроки и AI), 3D-машины без видимых вагонеток, три круга, четыре контрольные точки, аркадный дрифт, импульс и рекорды.
- Для игры нужен Minecraft-клиент 26.3 и запущенный Java-сервер; браузерный preview к проекту не относится.
