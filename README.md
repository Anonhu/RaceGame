# CHROMA RIFT — Minestom 26.3

Это **серверная мини-игра для Minestom**, а не Canvas/браузерный рендер. Minestom запускает настоящий Minecraft-сервер; мир строится сервером из блоков, а участники едут по неоновой кольцевой трассе на персональных вагонетках с цветным корпусом.

## Требования

- JDK 25
- Minecraft Java 26.3 client
- Доступ к Maven Central и Sonatype snapshots при первой сборке

Проект использует snapshot `net.minestom:minestom:26_3-SNAPSHOT` из Sonatype, поскольку поддержка Minecraft 26.3 в Minestom пока публикуется как snapshot.

## Запуск сервера

```bash
./gradlew run
```

Подключись к `localhost:25565`. По умолчанию используется offline-auth для локальной разработки. Для публичного сервера включи Mojang/Microsoft auth:

```bash
MINESTOM_ONLINE_MODE=true ./gradlew run
```

Хост и порт настраиваются через `MINESTOM_HOST` и `MINESTOM_PORT`.

## Заезд

1. `/race join` — телепортироваться на старт и сесть в серверную гоночную вагонетку.
2. `/race start` — запустить трёхсекундный отсчёт.
3. Удерживай **W + Sprint** для разгона. **A/D** меняют полосу; удержание Sprint при повороте накапливает заряд дрифта.
4. Правый клик с ячейкой **PULSE CELL** даёт импульс. Заезд начинается с тремя ячейками; дрифт может восстановить потраченный заряд.
5. Обойди овал **три круга**, проходя четыре портала по порядку. `/race leave` — выйти; `/race status` — узнать состояние.

Кастомное управление вагонеткой рассчитывается на сервере по вводу игрока. Перемещение вагонетки от клиента отменяется, поэтому клиент не может сам задавать позицию машины. Рекорды по UUID сохраняются в `data/chroma-rift-records.properties`.

## Реализация

- Java 25 + Minestom `26_3-SNAPSHOT`.
- Генератор Minestom строит обычный Minecraft-мир, неоновую трассу, ворота-чекпоинты и кристалл.
- `/race` (алиас `/rift`): до восьми игроков, серверные вагонетки, три круга, четыре контрольных точки, дрифт-заряды, импульс и рекорды.
- Для игры нужен Minecraft-клиент 26.3 и запущенный Java-сервер; браузерный preview к проекту не относится.
